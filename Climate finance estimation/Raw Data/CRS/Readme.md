# Where to stored .txt CRS Files

Place the raw OECD CRS bulk text files here (they are not shipped). `UploadBase.R`
expects these exact names:

- `CRS 1973-94 data.txt`, `CRS 1995-99 data.txt`, `CRS 2000-01 data.txt`,
  `CRS 2002-03 data.txt`, `CRS 2004-05 data.txt`
- `CRS 2006 Data.txt` to `CRS 2021 Data.txt` (one file per year, capital `D`)

Download source and details: `Econometrics/external-data.md`.
